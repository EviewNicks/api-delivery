1. Create Data bookings
   Bagian ini kita bisa membuat data pelanggan baru pada aplikasi Tripnesia. Pelanggan yang
   dibuat akan tersimpan di database dan dapat ditampilkan pada web atau aplikasi. Untuk
   akses Create Pelanggan masukkan link berikut ke Postman: https://tripnesia-vm51.vercel.app/api/bookings?action=create

   POST https://tripnesia-vm51.vercel.app/api/bookings?action=create

input

{
"name": "Budie namaku",
"type": "flight",
"destination": "Raja Ampat",
"date": "2026-01-15"
}

Response 201 created

{
"message": "Booking created successfully",
"data": {
"id": 10,
"name": "Budie namaku",
"type": "flight",
"destination": "Raja Ampat",
"date": "2026-01-15"
}
}
